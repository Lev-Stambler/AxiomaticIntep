Feature Explanation

It appears this feature is picking up on an end‐of–lexical unit or “boundary” signal—especially in formal, structured text (think addresses, document headers, dates, titles, and abbreviations) where a punctuation mark (typically a period) correctly ends a token. With the feature present the model “knows” to finish the unit (yielding a period and then a number, name or proper continuation), while without it the continuation instead runs into sub‐word fragments (e.g. “mn”, “vention”, “million”) that don’t fit. In short, it represents a learned cue for punctuation/abbreviation boundaries in structured text that helps guide proper next‐token generation.
