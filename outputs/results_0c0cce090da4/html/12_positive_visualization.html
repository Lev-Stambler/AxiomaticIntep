Feature Explanation

This neuron fires on the little “header” words that kick off a document or section across formats—i.e. the top‐level metadata or title markers (LaTeX’s “documentclass,” XML’s “dictionary” tag, license‐URL pieces like “opens…,” section headings like “median,” ad titles like “dumpster,” “DO NOT EDIT” banners, namespace/use/import lines, etc.). It’s essentially detecting the token you’d use to declare the kind or start of a file or section.
