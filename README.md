# Code for Feature Discovery from Axiomatic Principles

> Warning ⚠️: this is research code and the author's first experience using agentic AI coding (Claude Code). We thus apologize in advance for this simultaneously over and under engineered codebase.

## Getting Started
Install the Conda environment in `environment.yml` should set up most of the packages except for PyTorch. 
To install PyTorch, please see it's [getting started](https://pytorch.org/get-started/locally/) page.


The main package exists as "interventionfeatures" and can be run via the CLI command
```bash
️PYTHONPATH=$(pwd)/src/ python3 -m interventionfeatures.cli.main  ...
```
See runner.sh for the whole running suite.

We note that the use of "css" in this codebase coresponds to the Sensitivity Score ($\mathcal{SeS}$) in the paper.

## Installation

*Requirements*: use with Python 3.11

### Basic Installation
We use conda. The environment file can be found in `environment.yml`
Create the environment via
```bash
conda env create -f environment.yml
```

## Quick Start

### Config File
We use toml config files to specify our experiments.
See the `configs/` directory for examples.

### Env file

We require the following env variables in a .env file
```bash
export HUGGINGFACE_API_KEY=
export OPENAI_API_KEY=
```


### CLI Usage
```bash
# Find directions with high SeS
PYTHONPATH=$(pwd)/src/ python3 -m interventionfeatures.cli.main find-directions --config-file <Config File>
# Use automated labeling to explain the found features. Generate an HTML display for them as well
PYTHONPATH=$(pwd)/src/ python3 -m interventionfeatures.cli.main explain-display --config-file <Config File>
# Run the auto-faithfulness test. so
PYTHONPATH=$(pwd)/src/ python3 -m interventionfeatures.cli.main validate --config-file <Config File>

# The above commands should do visualization. To regenerate the index.html page, run the following
PYTHONPATH=$(pwd)/src/ python3 -m interventionfeatures.cli.main generate-vis --config-file <Config File>
```

## Architecture

The package is organized into several modules:

- **`core/`** - Core algorithms (CSS, data handling, search, etc.)
- **`analysis/`** - Analysis tools (explanations, faithfulness testing)
- **`utils/`** - Utilities (configuration, math, visualization)
- **`cli/`** - Command-line interface

### Tips and Tricks

#### Fast Development Without Reinstalling

For rapid development, you can run the CLI without reinstalling after each change:

```bash
# Option 1: Set PYTHONPATH (recommended)
PYTHONPATH=/path/to/your/repo/src python -m interventionfeatures.cli.main --help

# Option 2: Add to your shell profile for permanent setup
export PYTHONPATH="/path/to/your/repo/src:$PYTHONPATH"
```
